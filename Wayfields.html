Affordance Wayfields for Task and Motion Planning

A framework for representing manipulation affordances as objective functions over configuration space, enabling robots to generate motions that accomplish complex manipulation tasks.

Motion Planning Robot Manipulation Task and Motion Planning Affordances

Overview

Affordances describe the actions that an object or environment enables a robot to perform. They provide a natural representation for reasoning about how robots interact with the objects around them and can serve as an interface between high-level task planning and low-level motion planning.

However, traditional affordance representations, such as affordance templates, often specify actions using a sequence of end-effector waypoints. These representations constrain the robot's motion only at selected points along a trajectory, making it difficult to specify complex motions, enforce constraints throughout a motion, or account for obstacles between waypoints.

This research introduces affordance wayfields, a representation of manipulation actions as objective functions over robot configuration space. Rather than specifying a sequence of poses, an affordance wayfield defines regions that the robot must traverse to accomplish an action. The resulting objective function guides motion planning toward configurations that satisfy the desired affordance.

By combining affordance wayfields with obstacle and constraint fields, robots can generate motions that execute complex manipulation actions while avoiding obstacles and satisfying motion constraints.

Research Contributions

Affordance Wayfields

A new representation of manipulation affordances as objective functions over configuration space.

Actions are represented through ordered regions that a robot must traverse, allowing the representation of complex motions that may revisit the same regions of space.

Constraint-Aware Motion Planning

Obstacle fields and additional motion constraints are incorporated into the affordance objective function.

This allows motions to be generated while accounting for obstacles and constraints on the robot's configuration throughout the trajectory.

Randomized Gradient Descent Planning

A randomized gradient-descent planner generates motions by optimizing the affordance wayfield.

The planner can generate complex trajectories through multiple regions and accommodate goals defined as regions rather than individual configurations.

Affordance Wayfields

An affordance wayfield describes the sequence of regions a robot must traverse to execute a manipulation action. Each region defines a portion of configuration space associated with a particular stage of the action.

The cost associated with a configuration reflects its distance to the next region in the sequence. As the robot traverses a region, the objective function advances to the subsequent region, allowing the representation to capture multi-stage actions and motions that revisit portions of configuration space.

Planning Framework

The framework combines affordance objective functions with obstacle representations and a randomized gradient-descent planner to generate robot motions.

1

Define the Manipulation Affordance

A manipulation action is specified through a sequence of regions that the robot must traverse. These regions can be defined in configuration space or workspace, depending on the relevant aspects of the action.

For actions that primarily depend on end-effector motion, workspace regions can be used to define affordance wayfields.

2

Construct the Affordance Objective

The regions are used to construct an objective function over the robot's configuration space. The cost of a configuration is determined by its distance to the next required region.

This formulation supports complex actions involving multiple stages and repeated traversal of regions.

3

Incorporate Obstacles and Constraints

Obstacle fields and other configuration constraints are incorporated into the affordance objective.

These additional fields penalize invalid configurations and guide the planner toward motions that satisfy the manipulation affordance while avoiding collisions.

4

Generate a Motion Plan

A randomized gradient-descent planner optimizes the combined objective to generate a configuration-space trajectory that accomplishes the desired manipulation action.

Unlike waypoint-based representations, the planner can optimize the entire trajectory and accommodate goal regions instead of requiring a single goal configuration.

Applications

Affordance wayfields were demonstrated on complex manipulation tasks using a mobile manipulator. The experiments illustrate how affordance representations can support multi-step tasks involving interactions with different objects and the environment.

Table Assembly

The robot assembles a table by sequentially performing grasping, positioning, and screwing actions on individual table legs.

The grasp affordance guides the robot toward an appropriate grasping region on the table leg. The positioning affordance aligns the leg with the corresponding screw hole. Finally, the screw affordance generates the rotational motion needed to attach the leg to the tabletop.

These actions demonstrate how affordance wayfields can represent complex constrained motions that cannot easily be specified using end-effector waypoints.

Tool Chest Manipulation

The robot performs a sequence of manipulation actions involving a storage chest and the objects stored inside it.

Affordances include opening and closing drawers, picking and placing objects, and manipulating tools to perform specific actions.

The framework allows affordances to be associated with objects and reused across different drawers and object configurations.

Experimental Results

The experimental evaluation demonstrates the ability of affordance wayfields to generate motions for complex, multi-step manipulation tasks using a mobile manipulator.

Key Findings

  • Affordance wayfields enable manipulation actions to be represented as objective functions over configuration space.
  • The framework generates motions that satisfy affordance constraints while accounting for obstacles.
  • Complex manipulation actions involving multiple stages can be represented without requiring a predefined sequence of end-effector waypoints.
  • The approach supports manipulation goals defined as regions of configurations rather than individual target configurations.
  • Real-world demonstrations show the applicability of affordance wayfields to table assembly and tool-chest manipulation.

Future Research Directions

Affordance wayfields provide a foundation for connecting task-level reasoning with motion planning. Future work can extend this representation to more complex manipulation tasks and more expressive affordance models.

Task and Motion Planning

Integrate affordance wayfields with high-level task planning methods to automatically generate sequences of manipulation actions for complex tasks.

Kinodynamic Affordances

Incorporate robot and object dynamics into affordance motion planning to better predict the effects of manipulation actions involving physical interactions.

Complex Manipulation

Extend affordance representations to more complex motions involving multiple objects, articulated objects, and constrained manipulation.

Reusable Affordance Models

Develop reusable affordance representations that can be applied to different objects, environments, and manipulation tasks with minimal modification.
